# КЗпП України → Catala

Кодекс законів про працю України, перекладений у Catala — мову
літературного програмування для кодифікації законодавства. Призначення:
повторне використання норм у процесуальних документах (позовні заяви,
розрахунки, заперечення, відзиви).

## Структура

```
law.md                  — джерело (оригінальний текст КЗпП, 320 статей)
text/                   — увесь текст кодексу як літературні Catala-файли
  00_preambula.catala_en
  01_glava_I.catala_en … 22_glava_XIX.catala_en
kzpp.catala_en          — обчислювальний модуль (типізовані scope + тести)
```

`text/` містять дослівний текст усіх 320 статей, розбитий по 22 главах.
Catala трактує будь-який текст поза ```` ```catala ```` блоками як
літературну документацію, тож увесь кодекс є валідним Catala-документом.

`kzpp.catala_en` кодує **обчислювані** норми — ті, де є строки, грошові
суми, тривалості, вік чи відсотки. Декларативні статті (права, означення,
інституції) залишаються прозою без коду, бо обчислювати в них нічого.

## Використання

Потрібен Catala 1.2.0 (`opam install catala`). Спершу активувати
середовище:

```sh
eval $(opam env)
```

Перевірка типів:

```sh
catala typecheck kzpp.catala_en
```

Запуск конкретного scope (clerk сам збирає stdlib дат):

```sh
clerk run kzpp.catala_en --scope=VidpovidalnistZaZatrymku
```

Запуск тестів (усі сценарії з assertion):

```sh
for s in Test117Stelya Test44Mobing Test233Zvilnennya Test233Zarplata \
         Test51Pidlitok Test65Nadurochni Test108Nichni Test188Vik; do
  clerk run kzpp.catala_en --scope=$s
done
```

## Генерація коду для документів

Catala компілюється в OCaml / Python / C / JS. Наприклад, у Python для
вбудовування у генератор процесуальних документів:

```sh
catala python kzpp.catala_en -o kzpp.py
```

Після цього кожен scope стає функцією, яку можна викликати з конкретними
вхідними даними справи (дата звільнення, середній заробіток тощо) і
отримати юридично обґрунтований розрахунок із посиланням на статтю.

## Примітка про обсяг

КЗпП — 4723 рядки, 320 статей. ~85% — декларативна проза без обчислень;
вона збережена дослівно у `text/`. Обчислювана частина зосереджена у
`kzpp.catala_en`. Якщо потрібна додаткова стаття з розрахунком (напр.
ст. 83 — компенсація за невикористану відпустку, ст. 127 — відрахування
із зарплати), її легко додати тим самим шаблоном scope.
